# Curio Getting Started

An interactive mobile onboarding prototype for Curio, the AI scientist companion for children.

## Live demo

https://ez-ease.github.io/curio-getting-started/

Direct conversation demo:

https://ez-ease.github.io/curio-getting-started/?demo=ai

Direct desktop mockup:

https://ez-ease.github.io/curio-getting-started/?demo=ai&device=desktop

## Embed

```html
<iframe
  src="https://ez-ease.github.io/curio-getting-started/?demo=ai"
  title="Curio interactive conversation demo"
  loading="lazy"
  allow="microphone; autoplay; fullscreen"
  style="width: 100%; height: 820px; border: 0; border-radius: 24px;"
></iframe>
```

The app deploys automatically through GitHub Pages whenever the `main` branch is updated.
